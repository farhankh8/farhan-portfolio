## 🚢 Deployment

### Option A: Deploy to Vercel (Recommended)

```bash
# Install dependencies for the Tailwind build pipeline
npm install

# Build production Tailwind utilities (writes tailwind.css only)
npm run build

# Deploy to Vercel
npm i -g vercel
vercel --prod
```

Your portfolio receives a global CDN URL with edge delivery.

### Option B: Deploy to GitHub Pages

```bash
git init
git add .
git commit -m "feat: world-class portfolio v2.0"
git branch -M main
git remote add origin https://github.com/farhankh8/portfolio.git
git push -u origin main
```

Enable **Pages** in repository settings → select `main` branch → Save. Live at `https://farhankh8.github.io/portfolio/`.

### Option C: Instant Local Preview

```powershell
# Using Python built-in server
python -m http.server 3000
# Then open http://localhost:3000
```

Or with the Tailwind dev server for live utility rebuilding:
```bash
npm install
npm run dev   # watches input.css and rebuilds tailwind.css on changes
```
